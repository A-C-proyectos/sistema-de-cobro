Datos del negocio

💾 Respaldo de datos (en esta PC)

El sistema ya guarda todo automáticamente en este navegador. Para tener además una copia de seguridad como archivo en tu computadora (por ejemplo, al final del día o antes de una actualización), exporta un respaldo. Si necesitas restaurarlo — en esta PC o en otra — usa "Importar respaldo".

Importar un respaldo reemplaza todos los datos actuales por los del archivo.

🧾 Cierre de caja

Al finalizar el día, genera un archivo de texto con todas las ventas del día, los totales por método de pago y el inventario completo tal como quedó. Se descarga directamente a esta PC.

⚠️ Vaciar todos los datos

Borra por completo productos, clientes, proveedores, ventas y movimientos, dejando el sistema listo para empezar de cero. Útil si necesitas reiniciar el negocio desde cero en esta PC. Se recomienda exportar un respaldo antes de usar esta opción.
